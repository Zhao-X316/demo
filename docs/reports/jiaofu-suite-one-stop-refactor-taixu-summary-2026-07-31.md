# 教辅系统一站式体验与可持续重构 — 太虚五转综合报告

> 日期：2026-07-31\
> 输入：Lean Context、产品核心、技术架构、M2 方案与源码\
> 产出链：Osborn → Hegel → Bayes → Feynman → Debono

---

## 一句话结论

系统继续坚持傻瓜式一站式方向，施工从 R1-A 测试模块外移开始，用唯一合同和同批回执建立可复制的安全重构能力，再由真实老师数据决定后续 feature 与任务壳改造。

## 全程概述

本轮同时处理产品体验和代码施工：老师面对背诵、批改、题库、错题与图谱时，应获得打开即用、正常材料自动直通、只处理异常的流程；当前 `Exam.tsx`、`QuestionBank.tsx`、`question_performance.rs` 合计 11376 行，也需要可持续边界。

五转最终将产品层与事实层分开。老师看到统一入口、进度、异常和下一步动作；各模块继续保存自己的版本、事务、证据和审计事实。

当前唯一动作是把 `question_performance.rs` 末尾约 1060 行测试原样外移，建立“唯一合同 → 单因素改动 → 同批回执 → 独立复审”的施工方法。

## 关键认知转折点

1. **从“文件大所以拆”转为“职责与增长证据驱动边界”。** 行数只作预警，真正证据来自独立业务区段、状态密度、调用面和持续净新增。
2. **从“合并模块做一站式”转为“统一任务壳、分离领域事实”。** 背诵 effect、成绩发布、题目版本、错题事实和图谱推断继续保持独立生命周期。
3. **从“已有测试通过即可整体搬迁”转为“自动化只放行最窄动作”。** Rust 测试有直接回归，前端组件和状态编排继续冻结。
4. **从多份 R1 定义转为唯一执行合同。** Feynman 首审发现范围漂移，随后让阶段报告只引用合同。
5. **从精确概率转为证据等级和二元闸门。** R1-A 由五项验收全过或未过判定，老师价值等待真实试点更新。
6. **先建立重构能力。** 第一刀只移动测试组织，为后续施工建立可复制范式。

## 核心洞察（五转后沉淀）

1. **傻瓜式体验是一种表现层合同。** 老师只看到目标、进度、异常、证据和唯一主动作；内部状态与模型信息渐进披露。
2. **一站式不等于万能模型。** 统一入口读取各模块事实，跨模块写入仍由原事务持有，学习证据通过稳定 ID 和版本关联。
3. **文件拆分由行为边界驱动。** 测试、纯函数、组件、状态编排和生产 use-case 属于不同结构因素，每批只改变一种。
4. **产品价值由异常处理衡量。** 首次成功率、按钮数、异常定位时间、机器修正率和每百份主动操作时间比模型准确率更接近减负结果。
5. **分析报告不授权施工。** Osborn 保存方案空间，Hegel 保存收敛，Bayes 保存验证，Feynman 保存审查，Debono 保存价值；专项合同才授权代码动作。

## 最终判定 / 行动计划

### 当前执行：R1-A

- 原样外移 `question_performance.rs` 内联测试；
- 保持生产代码前缀字节级不变；
- 不改测试断言、公开符号、SQL、事务、IPC、DTO 或前端；
- 依次运行目标 9 项、`module-exam` 208 项、Tauri check、diff whitespace 和人工范围检查；
- 任一条件未满足即保持未完成。

### 后续候选

- R1.1：先给 `Exam.tsx` 纯函数建立直接测试；
- R2：完整 Tab 特征测试保护下逐个抽取 feature；
- R3：用状态迁移表验证 intake reducer 与请求编排；
- R4：调用图、事务所有权和失败注入齐备后拆 Rust 生产 use-case；
- R5：组合任务进度、异常卡和证据抽屉，用老师成对数据验证；
- 商业化与离线治理保持独立项目边界。

## 元认知收获

最有价值的发现来自阶段冲突：Osborn 防止产品方向被文件大小绑架；Hegel 明确任务壳与事实分离；Bayes 用真实反例收窄许可；Feynman 发现 R1 漂移和伪精确数字，促成 `CODEX.md` 与唯一合同；Debono 重新确认一站式和阶段拆分仍有价值。

两项经验可复用：阶段报告容易在同名阶段上产生细微差异，施工授权应独立落盘；没有可复算模型时，置信度应回到证据等级或二元验收。五转得到的不是一次性完整答案，而是一个足够小、能够立即验证、又能服务长期方向的起点。
